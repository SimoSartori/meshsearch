C++ reference
=============

``include/meshsearch/MeshGrid.h`` is the specification: it declares the
interface and states the guarantees it makes, and this page is generated from
it. Include it as ``#include "meshsearch/MeshGrid.h"`` and link the CMake target
``meshsearch::meshsearch``, which also provides the include path and requires
C++17. The `guide <guide.html>`__ explains how the members work together.

The version
-----------

The header ``meshsearch/Version.h`` is generated by CMake when the library is
built, and installed with ``MeshGrid.h``. It defines four macros:

``MESHSEARCH_VERSION``
   The version as a string literal, such as ``"0.3.0"``.

``MESHSEARCH_VERSION_MAJOR``, ``MESHSEARCH_VERSION_MINOR``, ``MESHSEARCH_VERSION_PATCH``
   Its three parts, as integer literals, for use in ``#if``.
